![Homepage mockup](file:///Users/shekharthathera/.gemini/antigravity-ide/brain/8e9ee372-f507-46d5-a1c5-2e703ab38c7f/signage_homepage_1790243873178.jpg)

## ✨ Overview
A high‑performance, **Next.js 16** website that positions **Signage Group India Pvt. Ltd.** as a premium, scalable visual‑communication partner. The site showcases the company's capabilities in signage, printing, fabrication and brand‑execution with modern UI/UX, dark‑mode aesthetics, glass‑morphism, micro‑animations, and SEO‑optimised markup.

## 🚀 Features
- **Next.js App Router** with server‑side rendering for SEO friendliness
- **Tailwind CSS** for a design‑system‑driven, responsive UI
- Dynamic hero section with gradient overlays and motion‑library animations
- Component library (`src/components/ui/*`) built for reuse across pages
- Optimised image handling via `next.config.ts` (remote Unsplash patterns & unoptimized flag for external assets)
- Robust SEO tags (title, meta description, Open Graph) generated per page
- Accessible navigation, dark‑mode ready, and performant builds (< 1 s dev start)

## 📦 Tech Stack
| Layer | Tool |
|-------|------|
| **Framework** | Next.js 16 (App Router) |
| **Styling**   | Tailwind CSS |
| **Icons**     | lucide‑react |
| **Animations**| framer‑motion |
| **Language**  | TypeScript |
| **Deployment**| Vercel (or any Node host) |

## 🛠️ Getting Started Locally
```bash
# Install dependencies
npm install   # or yarn install / pnpm install

# Run the development server
npm run dev   # starts at http://localhost:3000
```
The site should compile without errors – the build has already been verified with `npm run build`.

## 📦 Deploying
The project is ready for Vercel out‑of‑the‑box:
```bash
# If you use Vercel CLI
npm i -g vercel
vercel
```
Or connect the GitHub repo to the Vercel dashboard and let it handle the CI/CD.
